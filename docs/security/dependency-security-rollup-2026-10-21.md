The caller passes the requested size directly, bypassing the affected rounding implementation. Primary component evidence: [upstream aligned-new fix](https://github.com/gcc-mirror/gcc/commit/200183d4ab5d57575f3dfebc6af3baf649910b9e) excludes modern posix_memalign; [PBDS fix](https://github.com/gcc-mirror/gcc/commit/aaa8351f4d2e636f9680a1f0a8ebc2f0a60611e6) changes a template development header. ## R: implemented dependency and runtime changes

The CLI uses Rustls, has no native OpenSSL requirement, and does not depend on external subprocess programs. The runtime is therefore changed to **fully static musl PIE + static tini**, with current CA roots and the same UID 65532/working directory/CLI/feature behavior. This removes GNU libc, GNU loader, GCC shared runtimes, and system zlib rather than claiming vendor-disputed historical code was patched. Musl compatibility requires actual DNS/TLS/controller-fixture checks; it is not inferred merely from successful compilation.

Builder: digest-pinned Rust 1.99.1 Alpine 3.24. Maintained Alpine `/usr/lib/libc.a` is selected with `link-self-contained=no`; only LLVM unwinder is taken from Rust's self-contained directory. The link map asserts the exact selected libc archive. Both CLI and tini reject ELF INTERP/NEEDED entries during the build. This avoids retaining an older libc archive bundled by Rust while making a misleading system-package claim. Runtime: digest-pinned distroless/static Debian 13, refreshed trust-store bytes **and package provenance** from current stable Debian. No existing certificate advisory is blindly suppressed.

Stable Rust 1.99.1 was verified against the [official channel manifest](https://static.rust-lang.org/dist/channel-rust-stable.toml); consumer MSRV remains 1.96.0. All direct/dev crates were queried against the [crates.io sparse index](https://index.crates.io/config.json), excluding yanked/prerelease versions. Cargo.lock was refreshed within upstream constraints. Actions, cargo tools and Docker bases were checked against authoritative stable tags. Scan reporting includes every severity.
